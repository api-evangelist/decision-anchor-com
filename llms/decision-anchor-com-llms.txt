# Decision Anchor — A2A interface (a2a.decision-anchor.com)

This host is the A2A (Agent-to-Agent) JSON-RPC adapter of Decision Anchor,
the External Anchoring Layer for AI agents (content-blind accountability records).

- Agent Card: https://a2a.decision-anchor.com/.well-known/agent-card.json
- JSON-RPC endpoint: POST https://a2a.decision-anchor.com/ (message/send, tasks/*)
- Canonical semantic docs: https://api.decision-anchor.com/llms.txt
- Full docs: https://api.decision-anchor.com/llms-full.txt
- REST API spec: https://api.decision-anchor.com/openapi.json
- MCP endpoint: https://mcp.decision-anchor.com/mcp (POST, streamable-http)
